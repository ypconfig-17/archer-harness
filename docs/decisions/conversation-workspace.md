# 会话工作区与文件检查器

## 决策

视觉采用中性灰白外壳与完整白色阅读面：侧栏、窄栏与常规表面保持中性重量，强调色用于当前选中、页签、焦点、主操作与运行中活动。新对话为轻量入口，当前页签使用强调色文字与下划线。工作区与会话列平铺相接，以外壳底色和 1px 分界分层，不再用外壳留白与圆角把中间阅读面托成浮起的对话框。普通执行摘要去除常驻色块和外框，保持单行入口；计划不进入摘要，正文中只保留一行计划事件，当前计划另在输入区上方保留一行入口。任务边界与答复结果减少重复横线，正文保持主要对比。输入区采用更柔和的圆角与细边界，命令授权靠左，模型与推理控件靠右，窄窗口自然换行。所有色彩和结构刻度继续由语义 Token 提供，深色外观、四套界面主题与四套强调色保持同一结构。

桌面采用“应用窄栏 → 项目会话导航 → 中间工作区 → 文件检查器”。会话、执行活动与请求上下文是同一会话的三个阅读视图，放在中间固定的「会话 / 活动 / 上下文」标签。活动页只保留已提交事件的列表与单条记录阅读；上下文页按已提交的 INFER 请求快照扫描可折叠字符组成、输入 Token 趋势与默认收起的条目分组（消息、工具声明、参考与整理事实），并提供结构与原始内容两种视图。会话概览、调用详情与请求级能力来源不再作为活动页的二级视图。右侧工作台阅读工具确认的文件修改、本地 Git 工作区状态与会话已知字段，避免日志、请求与文件挤在同一窄栏；两类文件来源分开标注，不互相补齐。对象身份与打开规则见 inspector-workspace.md。

窄栏宽度 44px，项目导航 236px，刻度集中在 design-tokens.css。窄栏使用框架底色并以 1px 分界与会话列分层，macOS 下改为同族半透明表面以透出系统毛玻璃；会话列再以自身的边界与主工作区区分。窄栏承载对话、能力来源入口和设置；能力来源入口直接打开设置的全局来源页，不保留会话内的请求级来源视图。项目栏保留新对话、搜索、目录和异常历史入口。会话按最后一条已提交事实的时间排序，行尾显示轻量状态圆点与排队数量，不写相对时间文案；目录行汇总运行中会话数量。窄窗口隐藏窄栏，沿用原会话导航和菜单入口。

## 中间工作区

主对话按公开反馈分段：一条明确的模型公开文本开启一个阅读段落，其后的连续调用缩进归入同一段落，下一条公开文本、人工交互或 Turn 结束形成边界。普通调用按原事件顺序收成单行工具组，已结束调用折叠为“工具活动 · N 次调用”，单行内显示已记录耗时；失败、未知和运行中调用保持可见。每 Turn 只有一处累计执行摘要，默认收起，显示已加载工具调用数、工具确认的文件修改数、已知耗时、需关注数量与片段状态，并提供“查看全部活动”进入完整调试视图。计划声明不进入段落或摘要，只在历史位置保留一行计划事件（标题、步骤数、模型声明），点击查看版本与步骤变化；当前计划另在输入区上方保留一行入口，完整修订在活动中阅读。简版不逐条铺开模型思考、原始事件与内部身份。人工回答和当前授权保留各自原位边界，视觉收敛不改变日志。

任务的 completed、failed、cancelled 终态事实优先于尚未刷新的 activeTurn 快照；已结束任务不渲染可操作的授权与对账表单。取消请求和 cancelling 状态不代表停止，仍待对账的未知结果必须保留人工处理入口，不能因整理 UI 自动重试或丢弃追踪。

对话保留消息、正式答复、连续活动摘要、计划、授权和人工回答。工具行只做定位与快速扫读，不打开第二层详情；完整参数、结果与原始事件统一在「活动」页选择对应记录阅读。文件授权仍使用输入区原有的模式入口。

三个标签与内容通过 aria-controls 和 aria-labelledby 关联。方向键、Home 和 End 切换并聚焦标签。会话、活动与上下文保持挂载，切换不重建草稿、滚动、已选记录或请求选择；后台事件不自动切换视图。

## 文件检查器

简版执行记录保持单一层级：工具短行只做扫读，“查看全部活动”位于摘要行右侧并直接进入活动页；已结束任务的调用弹窗仍在原位展开单条明细。展开区最多 280px 且不超过窗口高度 40%，超出纵向滚动，支持键盘聚焦。调用片段分别显示执行中、调用已完成、需关注和推理记录；绿色只说明片段调用均已记录完成，不推断整轮任务成功。调用状态与任务终态继续分别表达。

活动页使用紧凑工具栏与按需详情：筛选保持控件宽度，不拉伸为整页表单；列表按任务与交互分组，选中记录后在同一页展开参数、结果与原始 JSON，关闭详情回到列表。

并排与最大化保持同一结构：目录树固定在左，选中文件的差异、源码或 Markdown 预览在右。目录列随可用宽度收缩，可通过工具栏文件夹按钮收起，让正文独占整栏。文件名、完整路径、未知增删量与未加载历史沿用已有事实规则。无变更显示空态，不添加示例数据。

目录树只组织选定任务中工具确认的路径，不扫描磁盘，也不代表完整工作区。收起和最大化不改变任务与文件身份。右栏只提供审阅、工作区、活动与会话概览入口，不提供上下文、请求快照、添加视图或文件暂存操作。工作区入口只读本地 Git 的 HEAD 与当前文件差异，明确标记为磁盘状态，不代表任务记录，也不与审阅计数合并。

## 影响与验证

活动页与页签共用同一条左边界，页面内不再二次居中。事件列表以轻量任务组和紧凑交互行组织，记录行保留时间、摘要与原始序号；选中记录后在同一页显示单一事实详情，包含结构化字段与完整原始 JSON，窄容器下详情替代列表并提供关闭返回。长路径单行省略，完整值通过提示和详情保留。文件检查器没有变更对象时只显示一个空态，不显示无效筛选、空目录与空阅读的重复分区。空态不影响已加载历史范围说明。

调整只涉及桌面呈现和本机导航，不改变 Runtime、Provider、授权、提交或恢复。原始事件、工具参数和配对结果保持不变。

验证包括桌面构建、类型检查、Lint、renderer 测试，以及 Electron 中的标签切换、活动记录选择与文件检查器收起与空态。有真实历史修改时检查目录选择和 Diff；空会话不能用示例内容冒充文件验收。
