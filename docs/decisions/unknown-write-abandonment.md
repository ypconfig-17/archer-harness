# 未知写入的人工放弃

## 背景

外部写入在断连或中断后可能已经发生。用户需要结束等待并释放当前 Turn，但现有 effect.failed、effect.cancelled 和 effect.completed 都表达了宿主尚未确认的外部结果，不能承担这个动作。

## 决策

使用 effect.abandoned 记录用户放弃追踪的原因和时间，原 Effect 保留 unknown。该事实只授权当前 Turn 结束，不授权重新执行或继续剩余计划。没有取消意图时 Turn 为 failed，有取消意图时为 cancelled；后续队列暂停。retry 仍是独立的人工决定，复用原 Effect，并在新的 started 事实增加 attempt。

这保护了“无法确认的外部写入不记为确定失败或取消”的性质，同时使用户能够结束一个无法继续对账的任务。恢复若只看到放弃事实，应补齐 Turn 终态，不能重新执行该写入。

## 重新评估条件

若能力能够提供可验证的外部结果查询，另行定义对账确认事实及其证据；不得通过修改 abandon 的含义把它变成写入未发生的证明。
