# 工作区差异与历史审阅

历史回执只使用已提交事实；任务审阅读取回执，工作区入口读取 Git，展示来源明确区分，不写入 Agent 事实。

差异展示统一经过 `@archer/ui` 的 HistoricalDiff，内部使用 `@pierre/diffs` React MultiFileDiff，提供统一和并排布局、语法高亮与上下文展开。文件路径只用于语法识别。无变化明确提示，不保留旧行渲染实现。

Git 接口使用 scope 参数：all 为 HEAD 到磁盘，staged 为 HEAD 到 Index，unstaged 为 Index 到磁盘。默认 all。列表只返回状态；path 参数只能命中当前状态列表，选中文件后读取两侧原文。前端按 Agent、范围和路径缓存，手动刷新同时刷新列表和详情。空范围仍可切换范围。

单文件最多 256 KiB，最多列出 200 个文件；二进制、超限或无法读取时不推断差异。读取不是原子快照。Git 只读能力不改变执行授权、日志提交与恢复机制。暂存区冲突的不可读侧保持未知，不提供合并操作。

验证：workspace-git 行为测试覆盖列表无原文、HEAD/Index/磁盘三侧内容、未跟踪、重命名、二进制及路由；changes-panel 测试覆盖历史来源与布局入口；运行 UI、Client、Server、Desktop 类型检查。窗口验收需检查明暗主题、窄栏、并排布局和长文件滚动。

差异、源码与工具修改详情统一复用复制自 shadcn/ui Base Nova 的官方 CodeBlock 原语，提供文件标题、复制、边界与代码阅读背景；差异正文仍由 Pierre 管理，不转换成 Markdown。统一布局在同列展示增删，并排布局分左右展示；切换时重建差异实例，避免沿用旧布局。单侧为空或内容相同时不提供布局切换，避免无意义操作。源码与缺少原文的回执只显示已有内容及行号，未知旧侧不推断为新增。

已记录内容由 CodeSnippet 组合官方 CodeBlockHeader / Title / Actions / CopyButton / Content / Line 与 useHighlightedCode。官方代码保留 data-slot 和 Tailwind 结构，主题适配只映射全局 Token；旧 title/text 式自定义 CodeBlock API 已移除。官方来源和适配范围见 packages/ui/THIRD_PARTY.md。验证包含组件组合、复制入口、布局点击测试、UI 构建和 Desktop 类型检查。

审阅和 Git 文件阅读只保留一个代码视图，不提供差异 / 源码 / 预览切换。两侧可读时展示差异代码块，旧侧未知时展示已记录内容；统一 / 并排仅控制两侧差异的排列方式。Git 比较范围继续保留。文件树布局在 packages/ui/src/ai/file-tree.css 独立维护，不随代码块样式替换删除；目录触发器的箭头、图标和名称保持同行，层级通过缩进表达。

同一文件的多个不连续修改记录不再上下堆叠，阅读区只显示最新片段的已记录快照及其可用旧侧，不跨不连续片段推断净差异。原始事件不删除。历史旧侧缺省时使用 Pierre File，旧侧已知时使用 MultiFileDiff；两者共用官方 Code Block 标题、复制和相同语法渲染体系。未知旧侧保持中性背景，只有已确认新增才使用新增背景。

任务审阅使用文件工具成功回执的 before / after，不依赖 Git。对话文件入口定位任务历史路径；Git 工作区保持独立入口，默认比较 HEAD 与工作区，不替代任务事实。传统 diffIndicators=classic 显示 + / − 和增删背景。

整体 write 在受控写入准备阶段流式读取旧文件，同一次读取生成 revisionBefore 并保留最多 256 KiB 的文本原文；CAS 使用完整摘要。旧文件不存在时明确 before=null。成功后经 FileWriteResult.metadata.before 传入工具 fileChange 回执，并随既有 Effect 结果提交；失败或未知写入不返回成功回执。二进制或超限旧文件不保留原文、不伪造空侧。外部进程仍可能并发修改，原文表示受控写入前观察值，不承诺操作系统隔离。edit 继续记录已有原文。Shell 等任意外部写入不自动生成文件回执。

连续修改只在上一段 after 与下一段 before 完全一致时合并为首次 before 到最后 after；不连续时显示最新已记录片段并提示，原始事实不删除。旧记录缺少 before 无法恢复，展示已有内容而不标成新增。验证覆盖无 Git 的覆盖写入、连续写入、新增、超限旧侧、恢复与审阅测试。

长行阅读通过公共「横向滚动 / 自动换行」分段控件选择，默认横向滚动，源码与差异共用该偏好。Pierre Shadow DOM 的排版适配集中在 renderers/diff-theme.ts；并排自动换行采用 T3 Code 的零最小列宽约束，防止长行改变列宽并引起重复换行。此设置只影响阅读，不改变比较内容、历史来源或执行事实。验证运行 diff-layout 行为测试与 UI 类型检查；窗口验收覆盖并排长行、窄栏、明暗模式和上下文展开。

文件阅读位置在当前面板实例内保留：历史审阅按 Turn 与路径隔离，Git 工作区按 Agent、工作目录、比较范围与路径隔离。切到新文件从顶部阅读，返回已读文件恢复纵向及外层横向位置。Git 内容加载完成后才恢复，异步内容尺寸变化期间继续尝试原位置；用户滚轮、指针或键盘操作后由用户接管，不再强行定位。不跨面板卸载或应用重启保存，也不保存 Pierre Shadow DOM 内部横向位置。此状态只属于阅读偏好，不进入日志；验证包含 review-scroll 的文件返回与来源隔离测试。
