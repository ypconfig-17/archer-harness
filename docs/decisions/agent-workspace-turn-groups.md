# Agent Workspace 工作轮次

对话阅读面采用 900px 最大宽度，与输入区共享 conversation-width Token。工作轮次使用开放正文与轻分隔线，不为每条消息增加卡片。

EventTimeline 按连续事件的 turnId 建立阅读组，保留原始顺序。不具备 Turn 身份的输入和通知保留独立位置，不猜测所属轮次，不将排队输入移动到其他事件之前。人工授权、调用与结束事实保持现有渲染和交互；计划只在输入区 CurrentPlan 显示一行入口，简版不生成计划事件行、段落或摘要区块。

结束摘要展示事实中的完成状态、工具调用数量和已知耗时，模型与用量仍按需展开。工具失败不推断整轮失败；停止请求不表示已停止。所有调整仅属于呈现，不改变 Contract、API、提交或恢复语义。

每段具有 Turn 身份的连续工作记录在开始处显示 Archer 头部，最终答复不重复头部。调用明细默认收起并由用户控制展开；累计摘要使用一行入口，不随 Turn 结束消失，也没有卡片底面。计划不进入对话阅读面，只在输入区保留当前入口。失败与停止使用独立区域并提供现有活动入口，不虚构恢复或重试动作。全局阻塞和队列仍位于输入区，因为它们约束后续提交而不是某次已结束调用。

验证使用 desktop typecheck 及 conversation、execution-timeline 行为测试，覆盖消息顺序、人工交互、未知结果、计划与消息头唯一性。实际视觉需另行核对深浅主题及 Inspector 展开布局。

## 可选计划与执行摘要

计划只在输入区以独立原生 details 呈现，默认显示标题、计划步骤完成数和模型声明来源，不进入对话段落或累计摘要。调用摘要保持单行，显示已加载调用数、调用状态和已知耗时，调用明细单独展开；没有工具调用时不生成零调用摘要。两者不在对话中并排，也不展示代表整体执行进度的百分比条；Inspector 展开后仍保留单列阅读。

完整活动入口仅在宿主提供实际跳转动作时展示。没有结构化诊断来源时不生成问题数量或检查结果列表，不从普通工具错误推断代码问题，也不提供绕过现有授权的应用修复按钮。计划、调用和文件变更继续使用现有事实投影，不新增后端协议。

## 授权节点与模式菜单

命令授权使用上下轻分隔、标准标题、独立代码表面及紧凑操作区，不用整块警示卡和程序聚焦外环。命令正文保留原文，不因视觉调整改变参数。命令模式入口使用公共 ui-menu 表面与原生 popover，支持点击外部及 Esc 关闭；模式选择仍调用既有确认流程。完全访问弹窗沿用公共标题和按钮，单列说明作用范围、当前命令和宿主权限。默认取消焦点、单次授权与任务级授权边界不变。

## 长对话阅读层级

展开的调用列表使用透明底面，悬停只强调当前行；参数摘要使用次级文字和常规字重，避免连续命令盖过最终正文。调用状态保留原有文字和语义色。输入框聚焦使用单一强调色边界，不叠加外光圈，内部按钮仍保留公共键盘焦点反馈。

模式菜单逐项解释每次询问、固定规则自动审批及跳过逐条询问的差异，并依照是否存在当前授权目标显示当前任务或后续任务作用域。完全访问不提高操作系统权限、不引入或放宽沙箱。执行摘要以“此前 N 次调用已完成”描述片段历史，与当前等待授权区分；不把片段成功当作任务完成。拒绝行为仍按现有任务终止语义标注，不用“拒绝此命令”暗示尚未支持的拒绝后继续执行。

纯推理片段没有调用或计划时不生成空执行摘要；人工交互仍原位保留。用户输入的阅读容器不标记为独立 Turn，避免把阅读分段数量当成真实轮次数。模式菜单进入确认前先恢复入口焦点，模态关闭时恢复该入口。

确认框取消后由输入区在下一帧恢复模式按钮焦点，避免模态卸载时浏览器原生焦点恢复覆盖业务聚焦。该流程保持取消默认焦点与 Esc 关闭，不提交权限修改。

Agent 头部和任务元数据采用组内间距，不额外叠加消息级上下边距。调用列表展开与 Inspector 并排时保持独立滚动，长表格及代码标识按现有 Markdown 规则换行。

## 授权视觉层级

命令授权采用单层轻琥珀边界与中性阅读面，标题旁显示终端命令标签。目录行使用文件夹图标，原始命令使用独立代码表面和细边界；动作保持公共按钮及主题强调色。完全访问确认框以浅中性说明区组织宿主权限及文件工具边界，并用语义图标区分当前命令授权和权限提醒。菜单、卡片和模态为三个独立交互面，不同时强制常驻；示意图中的通知、头像与搜索不作为授权组件新增功能。

## Conversation First

对话简版每个 Turn 只在首个普通活动位置呈现一个累计执行摘要。摘要为无卡片单行入口，展开后按原顺序列出本轮调用；计划不是摘要内容，只由输入区 CurrentPlan 展示。公开反馈文本成为自然段落起点，后续连续调用作为缩进工具组附在其后；没有公开反馈时只显示中性工具组，不编造阶段名称。后续活动仍在原位置，不搬入摘要；人工回答、授权与异常保留原位置，不改变事件、执行或恢复语义。完整活动入口使用普通文档流，不再绝对定位。Agent 头部不重复显示“工作记录”，任务锚点保留但不单独占一行元信息。
