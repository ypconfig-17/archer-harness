# 主窗口内的设置工作区

## 结构与职责

设置是 Archer 主窗口内的完整工作区，不是系统全屏、新窗口或覆盖对话的模态。设置导航替换主导航，检查器随主工作区暂时隐藏。顶部保留原生窗口按钮和拖动区域；设置分类只有一列，不增加全局图标导航。

导航宽 220px，包含返回应用、搜索设置、现有分类与生效范围。分类导航复用包内 Sidebar 菜单原语（分组、菜单、菜单项与菜单按钮），语义保持页面级导航而非页签；只按设置规范覆盖行高、字阶、选中表达与行内焦点描边，不套侧栏外壳、不注册折叠与快捷键。正文居中、内容宽度 800px，沿用现有标题、设置行和保存栏。普通偏好在行内修改；上下文概要进入完整策略详情，模型服务列表进入单个服务详情。删除和未保存确认仍使用小型原生 dialog，不改变其提交语义。

搜索只索引静态分类、说明与设置项关键词，不搜索凭证、输入值、服务器数据或用户文件。匹配时定位第一个分类，导航只显示匹配分类；无结果明确提示，不销毁隐藏的编辑器。Esc 清除搜索或处理内部浮层，不把设置页面当成弹窗退出。

## 返回、草稿与运行边界

主工作区保持挂载，以 hidden 和 inert 隐藏并隔离输入。返回应用后恢复原会话、输入草稿、对话阅读位置和检查器选择、宽度与最大化状态。设置打开期间，主会话导航快捷键与菜单动作不能操作隐藏区域；后台订阅继续接收事实，不停止任务。

切换分类和进入、返回策略详情不卸载模型与上下文编辑器。返回应用、打开其他会话或添加工作区仍经过同一未保存检查：保存期间禁止离开，有草稿时先询问继续编辑或放弃。移除服务只改变编辑草稿，明确保存后生效；页面切换不改变权限、模型或 Runtime 配置。

即时偏好、显式保存、服务端配置和本机配置继续使用已有语义。布局状态不写入 Agent 日志，不产生能力调用，不自动保存配置。

## 验证

检查页面主体不是 dialog、静态搜索能匹配设置项且不索引未知值；构建包含主进程与界面类型检查，执行相关界面测试与 Lint。Electron 核对进入与返回、主工作区恢复、搜索、二级详情、未保存确认取消和原有控件。未保存或删除的最终提交不为验收而触发，不做浏览器测试。
