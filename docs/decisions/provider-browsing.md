# 设置中的能力来源浏览

能力来源是只读注册信息浏览，不是能力管理器。设置采用三个层级：Provider 横向小卡片 → Provider 能力列表 → 单个能力的契约详情。三个层级在同一正文内替换，使用返回导航，不开新窗口或模态，不并排显示列表与 Contract。

## 呈现与导航

入口为两列 88px 高横向小卡片，图标容器 36px，名称使用 UI 字号与 medium 字重，说明使用辅助字号并限制两行。默认无阴影，悬停仅改变背景，不缩放或位移；内容区域不超过 720px 时单列。数量按实际 capabilities 计算，不按 Provider 名称补造文件、模型或技能。

描述优先采用作者公开的来源说明，否则概览已公开的能力 summary。契约类型用于通用标签与图标，不按 files、shell 等来源 ID 推测用途或权限。非工具契约可使用 description；工具的模型声明正文不作为入口的大段说明。

Provider 详情使用两行紧凑能力列表。选择能力进入独立详情，展示完整 CapabilityRef、执行与交互声明、可公开输入 Schema 和原始能力 metadata。来源 identity 可按需查看，但不代表代码签名或外部内容校验。进入详情聚焦标题，返回聚焦原列表项或卡片。

搜索位于发现入口，同时匹配来源与内部能力；进入详情后不重复展示搜索框，返回后保留原搜索结果。命中能力时提供直接进入详情的结果，保留来源名称；从搜索进入的返回到结果，来源面包屑也可进入完整能力列表。来源卡片的聚合描述不导致其所有能力自动匹配关键词。

## 数据与契约边界

数据继续来自 Client 的现有 providers 查询，不新增 Camp 注册机制、扫描、调用或配置接口。技能正文与资源通过只读接口按完整引用读取，仅在用户打开详情或资源时发生，不重新扫描目录。完整引用包含 Provider、能力 ID、Contract 与 revision；刷新后来源或 revision 消失时明确失效，不把旧选择静默替换成新实现。

结构化 Schema 默认显示当前层字段名称、声明类型、必填性与说明。引用、组合、嵌套和其他约束不猜测展开，提示用户查看原始 Schema。原始阅读是服务返回对象的格式化 JSON，不从字段概览反向生成契约，也不声称保留网络载荷的原始字节。完整能力声明包含其余公开 metadata；没有公开输入 Schema 时明确说明，不补造权限或参数。

已注册不等于已授权、健康或已提供给某次模型请求。这里不展示启停、运行测试或授权按钮，也不主动枚举模型目录。技能详情展示名称、描述、来源、路径、正文与资源清单；正文和单个参考文件只在用户展开时读取，固定到已注册引用，不代表执行技能或扩大权限。将来增加类型专用阅读，仍必须以该 Provider 实际公开的数据为依据。

本结构只用于设置的全局来源浏览。会话与活动页不提供请求级来源视图，也不把全局注册信息伪装成某次模型请求的实际声明。

## 验证

行为测试检查内部能力搜索、未知来源、空能力、完整引用及 Schema 不变性；入口渲染检查真实来源与默认不展开技术详情。桌面构建、类型检查、Lint 与界面测试配合 Electron 检查卡片、逐层返回、搜索直达及 Schema 切换。无操作按钮意味着验收不执行能力，不保存配置；不做浏览器测试。


### 来源与能力的双列浏览

设置中的一级 Provider 和二级能力（含技能与搜索结果）统一使用双列横向小卡片，内容区域不超过 720px 时收为单列。Provider 高度 88px，能力卡片高度 112px；名称单行截断，用途最多两行，来源与执行声明独立呈现。截断只影响列表，详情保留完整声明。

彩色资源图标使用用户提供的 `现代应用图标网格界面.png`，原图保存于 `apps/desktop/renderer/src/assets/capability-icons.png`，由 CSS 图集窗口显示无文字的图标区域。图标尺寸和图集刻度集中在 design-tokens.css。Provider 与已知技能通过有限的本地展示映射选择图标，未知技能使用书本，未知来源使用系统图标；不再按身份随机分配颜色或徽记。图标映射不参与 Camp 解析、能力分类、授权或执行，不添加图中尚未接入的入口。

三级详情继续采用单一阅读区，不双列展示技术正文。按钮、导航和活动图标继续使用 Phosphor regular。图集保留原图的浅色底座，深色外观中也不对图标反色；暗色专用画稿尚未提供。


### 技能新增入口

能力来源首页和 skills 二级页在宿主支持时提供“创建技能”“导入 SKILL.md”。操作在当前内容区进入编辑页，不新增窗口；导入仅支持单个文件，附属资源限制明确提示。成功显示实际路径与“待重启加载”，不将磁盘新增伪装成 Camp 已注册能力，不自动重启或中断任务。创建与导入的边界见 docs/decisions/local-skills.md。


### 技能编辑页的排版

创建与导入技能使用最大 640px 的单列编辑区，宽度随窗口收缩。顶部为轻量返回导航、技能图标、18px 标题和次级说明；共享 FormField 在此页清除上下外边距，仅由 16px 表单间距控制节奏。正文编辑区初始约 200px，可纵向调整，不自动铺满视口。

底部轻分割线组织加载说明、取消和保存按钮；窄窗口自然换行。格式与容量说明贴近字段，不在页首堆叠。保存期间输入与退出操作禁用；本页返回和取消在未保存时使用共享确认框。编辑、保存和待重启加载的宿主语义保持不变。
