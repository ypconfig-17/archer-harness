# 设置阅读布局

设置沿用独立分类导航与有界正文，覆盖通用、外观、快捷键、模型、上下文、能力来源、对话记录、工作区和关于页面。标题使用阅读面背景，组标题、说明和控件形成三级层次，不为每个设置添加卡片。

通用中的文件访问与启动偏好使用公共 SegmentedControl，两项选择即时保存，取值和默认行为不变。工作区与模型保留选择器，固定行为保持静态值。

各分类共用行布局、表单间距、保存反馈及断行规则。模型表单与中性设置说明区遵守同一间距，能力来源的技术标识按需展开，记录和工作区的操作允许换行。外观保留主题缩略卡、强调色行和折叠预览。中等宽度外观缩略卡转两列；窄窗口的设置项和模型表单转单列，避免控件挤压说明。

所有颜色与尺寸复用语义 Token，不更改业务配置、服务 API、授权或保存边界。模型与上下文仍显式保存，本机偏好仍即时保存。验证使用桌面类型检查、构建以及 settings-workspace、model-settings-draft、provider-browser 测试；实际视觉验收需要分别检查深浅模式、窄窗口、长路径、空列表、加载失败及未保存退出。
