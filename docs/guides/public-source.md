# 公开源码边界

公开源码包含实现、行为测试、使用与架构文档，以及第三方许可。根许可证使用 Archer Harness contributors 署名；第三方作者与版权声明保留。

本机开发指导、过程记录、验收材料、真实会话、模型配置和凭据不属于公开源码。忽略规则只控制后续文件跟踪，不能清除已有 Git 历史中的内容或提交作者身份。

首次公开使用不带原 .git 的干净源码目录建立新仓库。提交前配置希望公开的作者名称及 GitHub 提供的 noreply 邮箱；不要直接沿用本机默认身份。不要从原仓库推送旧分支、标签或其他历史引用。

测试中的虚构路径、示例邮箱与合成令牌用于验证行为，不是运行凭据。常见模式扫描没有发现问题并不构成完整泄漏保证；图片内容、二进制文件与第三方权属仍需分别确认。
