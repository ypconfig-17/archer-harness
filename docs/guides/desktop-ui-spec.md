> 色彩与主题默认值以 [桌面外观与主题系统](../decisions/desktop-theme-system.md) 为准：明暗模式、界面主题与强调色三个维度自由组合，默认深色、Graphite、Graphite Iris，保留有效的本机偏好。本文中的具体色名只描述当前预设，新增界面主题只能改变中性层，新增强调色只能改变强调色 Token。

# Desktop UI 设计规范

整体视觉采用中性灰白外壳、独立白色阅读面和轻量导航，强调色用于当前选择、焦点、主操作与运行中活动。当前布局与视觉以 [会话工作区与文件检查器](../decisions/conversation-workspace.md) 为准，优先于下文早期浅蓝导航与实心新对话的描述。工作区与导航平铺相接，以 1px 分界和各自底色分层，不使用外壳留白与圆角托起中间阅读面。普通执行摘要无外框，计划只在输入区保留一行入口；调用明细展开区仍限高滚动。输入区授权靠左，模型与思考靠右。验证包含主题对比度、阅读布局、构建及 Electron 实机核对。

工作区结构以 [会话工作区与文件检查器](../decisions/conversation-workspace.md) 为准：单侧栏（默认 320px，可拖拽 260–420）承载项目与会话导航，中间「会话 / 活动 / 上下文」，右侧工作台。侧栏在 macOS 下使用同族半透明表面透出系统毛玻璃，顶部留出系统标题栏拖动区；不再保留独立的应用窄栏。右侧工作台默认列出审阅、工作区、活动与会话概览四张入口卡；审阅与工作区固定为左侧文件树、右侧阅读区，目录可收起，并排与最大化共用同一结构。其他章节中的右侧多标签与文件左右比例由该决策替代。

侧栏折叠为图标栏时，顶部显示可点击的 Home 图标，提示与无障碍名称为「返回首页」，点击切换至首页并展开侧栏，恢复项目与会话导航，不停止或删除当前会话。展开态保留 Archer 品牌。验证时检查折叠态图标、提示、键盘操作及返回首页后的侧栏展开与会话保留。

## 目标与适用范围

本规范约束 apps/desktop 的所有界面：主窗口、侧栏、首页、对话、输入区、检查器、设置工作区及其子页、所有菜单和模态弹窗。未来 Web 独立设计。设计基准是设置与检查器条目导航的紧凑、对齐、轻边界、清晰选中态。参考 Codex 的比例与层级，默认组合使用冷调鸢尾强调、石墨灰白中性表面与深灰正文；品牌资源独立于主题。颜色由语义变量获取，不作为业务组件常量。

桌面质感来自固定工具栏、稳定导航列、正文与操作分离、控件尺寸一致、可控滚动和完整交互状态。不得通过全局缩小文字、加阴影或套卡片代替结构设计。

## 视觉刻度与公共组件

所有刻度在 ui/theme/design-tokens.css 维护，业务组件不得另建字号、颜色和圆角体系。功能图标只使用 Icon 与 Phosphor regular；图标尺寸取 xs/sm/md/lg，品牌独立。

| 元素 | 规则 | 使用位置 |
| --- | --- | --- |
| 正文 | 14px / 24px，regular | 对话、说明、阅读内容 |
| 操作与表单 | 14px / 20px，regular | 输入、按钮、设置值 |
| 导航 | 13px / 20px，regular；目录 medium | 侧栏、菜单、设置分类 |
| 辅助信息 | 12px / 18px | 分组、路径、状态、元数据 |
| 窗口标题 | 16px / 22px，medium | 弹窗标题与设置页标题 |
| 代码 | 12px / 18px，等宽 | 源码、命令、Diff、原始数据 |
| 密集行 | 28px | 检查器条目、菜单 |
| 标准行与控件 | 32px；会话导航 30px | 按钮、输入、选择器、会话导航 |
| 工具栏 | 40px；主窗口栏 44px | 弹窗头、检查器、窗口头 |
| 圆角 | 小控件 6px，浮层 12px，输入区 12px | 不用大胶囊搜索或大圆角卡片 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px | 相邻控件、组内、组间与区域边距 |

表面分为白色阅读层、浅蓝导航和工具层、浮起菜单与模态层。常驻内容不用阴影；输入控件使用细边界，菜单与模态才有可辨别的悬浮深度。强调色用于当前选择、焦点、主要动作与运行中活动，并以低比例混入普通按钮、字段与选择器的表面和边界，危险色仅用于明确危险动作或错误。深色主题使用相同结构与语义色。

基础 Button、Input、Card 采用 shadcn/ui 官方 Base UI 源码，颜色与结构刻度经 `@archer/ui` 的 Tailwind 桥接读取本规范 Token；Surface.tsx 与 surfaces.css 负责浮层标题、表单字段组合、菜单、管理按钮和操作栏。业务只负责内容及关闭、提交等行为。普通按钮、输入、下拉触发器与仅图标动作统一读取公共控件表面，业务不另写按钮样式，也不出现未套用公共按钮类的裸 `<button>`。禁止业务组件复制浮层规范或用宽泛的后代尺寸规则影响嵌套菜单。下拉选择统一使用 `ui/primitives/Select`，展开列表与选项按浮层 Token 绘制，不接受系统原生下拉外观；复选框、单选框与滑块使用强调色作为系统强调色。

## 主窗口比例

四态结构见 [桌面母版](../design/desktop-baseline.html) 和 [设计取舍](../decisions/desktop-visual-baseline.md)。1600px 窗口采用 320px 单侧栏、弹性任务区和 400px 检查器。初次检查器关闭，主动开关与有效宽度保存在本机；最小宽度 320px，普通并排最多占面板容器 70%，同时保留会话至少 360px。长代码、Diff 和日志通过最大化进入专业阅读状态。历史恢复异常入口放在底部工具区，仅保留图标与数量。

连续工具交互默认折叠，搜索或选中后展开，原始编号、顺序和内容不变。原始事件用任务身份分组，需关注筛选来自真实警告和错误，不凭工具结果推断任务成功或失败。

## 区域设计

| 区域 | 结构与内容 | 不采用的做法 |
| --- | --- | --- |
| 左侧栏 | 小品牌行、轻量新对话、与行同底色的紧凑搜索、项目目录分组、底部设置与服务状态；主列表独立滚动，默认只展开当前项目 | 大号入口、深色重选中、搜索框常驻边框、每个分组套卡片 |
| 文件夹与会话 | 文件夹图标列、文字列与行尾信息列；目录保留文件夹图标，会话以缩进表达归属，标题直接起排且不保留图标列；长标题省略并保留完整提示；项目操作以行尾浮层菜单出现，不占文字列；行尾显示轻量状态圆点与排队数量，目录行汇总运行中任务 | 悬停后文字位移、状态点、排队数与菜单重叠、用推断结果替代事实、在行尾渲染相对时间文案 |
| 首页 | 有限阅读宽度、品牌欢迎与同款输入区；有真实内容才显示列表 | 仪表盘统计卡、占满页面的大表单 |
| 对话 | 开放白色阅读面，780px 阅读线；标题、段落、引用与代码层级清晰 | 每段卡片、过量装饰、全宽长正文 |
| 执行过程 | 公开反馈成为自然段落起点，连续工具缩进分组并显示读取 / 修改 / 执行分类计数；累计摘要单行、无底面且指标之间以低对比分隔；失败与停止使用正文层级；询问在发生处展开；计划只在输入区一行入口，历史计划展开限高 | 整轮大卡片、重复计划卡片、把计划阶段当执行段落、限高执行内滚动、重复等待提示、输入框式错误卡片 |
| 输入区 | 正文输入与底部工具栏两层，单一细边界；模型、思考、授权低一级；发送为主动作 | 多重外框、工具栏争抢注意、横向溢出 |
| 检查器 | 标题栏、视图工具栏、导航与阅读区、状态栏；保持已认可的条目质感 | 大搜索框与正文大小的长列表 |
| 文件视图 | 顶部路径及查看方式、左侧文件树、右侧阅读区；树可收起 | 上下堆叠文件树与 Diff |
| 活动 | 与页签、工具栏共用左边界；事件按任务和交互分组，记录行保留时间、摘要与原始序号，单条详情展示结构化字段与完整原始 JSON，窄容器下详情替代列表 | 请求快照、能力来源、会话概览或调用详情等第二套活动子视图 |
| 上下文 | 标题区提供请求选择、`#n / 总数` 与前后翻页；四格指标只列输入 Token、消息数量、工具声明与缓存 Token；「结构」视图左侧为可折叠的字符占比条带、摘要单行的近期 Token 趋势与默认收起的可折叠条目分组，右侧为请求概览、已选上下文与整理事实，两栏可拖动；「原始内容」视图直接阅读已提交 JSON 快照 | 请求快照以外的执行状态、用全局注册信息补齐历史请求、把字符占比标成 Token、把按字符分摊的分段标成模型实际分类用量、逐字段卡片、图表库或关系图渲染条带 |
| 设置 | 主窗口内页面：220px 分类导航、返回应用、静态搜索、800px 正文与固定保存栏 | 管理后台卡片墙、巨大偏好选项卡 |
| 设置行 | 左标签及辅助说明、右侧控件；长表单用明确标签逐项排列 | 标签和值分散、无边界的大面积输入 |
| 记录列表 | 主标题、次级路径、状态、轻量行操作；范围信息必须真实 | 按钮矩阵、大数字统计、假装完整的数据 |

上下文扫描只读取已提交请求：四格指标中的输入与缓存 Token 来自该次推理返回的 `usage`，消息与工具声明数量来自请求快照；横向条带按正文字符数计算占比，不换算成 Token，也不伪造分类 token。Token 趋势只把已提交 `usage` 的输入总量画成柱高，窗口可选最近 9 次、18 次或全部请求，当前请求高亮并显示较上次变化；堆叠分段只按请求快照字符占比示意构成，缺失用量的请求保留位置但不画柱，页面明确注明分段不是模型实际分类用量。字符占用区块默认展开，可用标题收起后直接阅读条目；条目分组默认全部收起，首屏只保留分组标题与计数，搜索命中时自动展开，点击条带打开对应分组，切换请求后重新回到全部收起；趋势的当前值与较上次变化收在图表上方一行，图表占满左栏宽度，最近与最早请求的数值徽标向内对齐，不越过内容边界。条带点击、搜索、类别选择与趋势柱点击只改变条目视图或当前请求；「原始内容」原样展示请求与返回 JSON。

上下文整理只在当前阶段显示一处轻量提示，任务结束后不在答复里保留整理记录；逐请求的提交、响应、采用状态与估算在「上下文」页签阅读。答复后只保留结束事实、变更入口和真实需关注项构成的结果摘要；耗时、调用次数、模型、推理次数与累计用量默认收进详情。文件历史、模型实际请求和当前磁盘内容必须区分，未知数据不补造。

## 浮层及内容规范

| 类型 | 需要的结构 | 尺寸与状态 |
| --- | --- | --- |
| 操作菜单 | 图标、名称、必要快捷键；危险动作与普通动作语义区分 | 28px 行高，小圆角行，锚定入口；不挤压嵌套文字 |
| 确认与删除 | 紧凑标题、说明后果、错误、右对齐操作栏 | 小/中窗口；取消优先聚焦，提交中禁止重复动作 |
| 重命名 | 标题、带标签的输入、错误、取消/保存 | 中窗口，不使用巨大标题或无样式输入 |
| 工作区选择 | 标题、选择中/失败/空态、底部操作 | 复用原生文件夹选择，不伪装文件浏览器 |
| 工具历史与异常记录 | 固定标题、可滚动列表、明确范围、底部动作 | 大窗口，内容不能撑破窗口；记录复用紧凑行 |
| 设置及未保存确认 | 分类与内容分区；未保存时说明涉及部分并提供继续/放弃 | 保存、丢弃、关闭各自保持原有业务语义 |
| 授权与人工回答 | 目标和命令、回答控件、明确选择、折叠详情 | 保留原有授权范围、取消和未知结果的解释 |

所有弹窗内容中的输入、选择器、正文、代码、错误与操作栏同样受本规范约束。不能只统一外框。普通表单使用共享控件边界与焦点；代码用小字号和浅色表面，空正文不渲染空框。长命令和原始 JSON 保留可复制原文，按需横向滚动。

## 交互、缩放和可访问性

- hover 仅增加轻量表面；selected 使用浅强调填充，focus-visible 使用强调色轮廓，disabled 保留可读性。
- 所有图标按钮有明确名称；字段有可访问标签，长文本有完整提示。不可只用颜色表达状态。
- 模态使用原生 dialog，菜单使用 popover；Esc 只处理当前浮层，关闭后焦点返回入口。业务提交中是否能关闭由业务决定。
- 每个区域至多一个主滚动区，长输出在自己的阅读区滚动；窄屏不挤掉操作，不产生工具栏横向滚动。
- 检查器并排最多占面板容器 70%，同时保留会话至少 360px；最大化正文与标题共用 960px 上限；最大化为不透明整窗阅读面，不透出侧栏与会话；专注模式临时收起侧栏，不覆盖本机偏好。
- 尊重系统字体缩放和 reduced-motion；标题不能靠固定高度裁剪。

## 三层 GUI 规范与主题边界

1. Design Foundation：字体、结构刻度、语义颜色、基础组件与可访问性。
2. Workspace Layout：导航、对话、检查器、设置、滚动与窗口空间。
3. Agent Interaction：见 [Agent 交互规范](desktop-agent-interaction.md)，约束计划、活动、授权、人工回答、重连、未知结果和历史变更的事实投影。

外观由三个独立且可自由组合的维度组成。外观模式 appearance 支持浅色、深色、跟随系统；界面主题 baseTheme 支持 Graphite、Midnight、Slate、Warm，决定窗口、侧栏、阅读面、表面、文字与边界；强调色 colorTheme 支持 Graphite Iris、Slate Teal、Carbon Amber、Dusty Rose 四套预设与自定义 HEX。默认组合为深色、Graphite、Graphite Iris。界面主题只覆盖中性层，强调色只覆盖 `--accent-default`、`--accent-text` 与 `--accent-foreground`，二者互不替换；自定义强调色在运行时推导可读的文字与前景色，以内联变量覆盖三个角色。设置立即切换并持久化到桌面本机偏好，不属于 Agent 或 Runtime 配置。密度维度保持独立，目前不提供密度选择器，不增加未使用的运行配置。

主题解析在 ui/theme/theme.ts；`data-appearance` 标记最终明暗，`data-base-theme` 标记界面主题，`data-theme` 标记强调色。组件继续使用 --canvas、--sidebar、--panel、--text、--secondary、--muted、--accent、--hover、--selection、--border 等语义别名，别名在 design-tokens.css 中映射到规范变量。--accent-text 用于中性表面上的强调文本，--accent-subtle 与 --accent-subtle-hover 用于选中表面，--accent-border、--accent-focus-ring 与 --accent-muted 分别承担强调边界、焦点环与次级强调，--on-accent 用于填充上的文字，--state-focus、--state-disabled、--state-pressed 明确交互角色。选中表面上的正文使用 --text-primary，避免强调文字在混合底上低于 4.5:1。完整主题必须覆盖表面、文字、边界、选择和动作；状态色按明暗定义，与强调色分离，运行中与当前活动使用强调色，成功、失败、警告与等待授权保持独立语义。原生标题栏从相同的 --bg-sidebar 和 --text-primary 读取颜色，不维护主题颜色副本。

新增界面主题只添加中性 Token 块与 BASE_THEMES 定义，新增强调色只添加 COLOR_THEMES 定义和对应强调色块，不修改 Sidebar、AgentDetail 等业务布局。主题不能覆盖字号、间距、行高、密度、圆角或功能位置。Logo 独立保持品牌。主题切换不需要重启；系统明暗变化只影响跟随系统模式。代码高亮保持语法角色配色，不简单反转。

验证包括主题解析、四套界面主题与四套预设及自定义强调色的默认值、本机偏好恢复、非法值回退、中性层与强调色互不影响、布局刻度不被主题覆盖，以及全部界面主题 × 预设 × 明暗下关键文字和动作的对比度检查。按用户要求不执行浏览器测试；程序检查不代替 Electron 实机视觉验收。

上下文设置的策略模板使用单个选择器与当前说明，不展开所有模板说明为大块选项。模板切换仍通过原来的未保存确认，选择不等于保存；生效模板、草稿和自定义副本保持区别。

组合搜索控件由外层提供唯一边界，内层输入不得再次套表单外框；聚焦只改变外层描边颜色，不叠加第二层焦点光圈。嵌套 dialog 的 cancel 事件必须阻止向父层传播；Esc 只取消当前确认，不同时关闭设置。

窄窗口输入区的模型、思考、授权控件自然换行，不采用横向工具栏滚动；发送和停止操作保持可见。文件树优先留出文件名空间，增删统计在阅读标题与完整提示中呈现，不挤压目录行。

实机验证需记录范围、结果与未覆盖项。验收采用 Electron 原生窗口，测试说明必须区分静态页面、历史记录与真实执行状态。

## 检查器与轻量浮层的细则

检查器的产品信息架构以 [会话工作区与文件检查器](../decisions/conversation-workspace.md) 为准：中间的「会话 / 活动 / 上下文」是三个固定视图，右侧工作台是文件审阅、工作区 Git、活动与会话概览的入口页。工作台首页只列已有对象：打开审阅、打开工作区、打开活动、打开会话概览，卡片显示各自的已确认计数、本地 Git 标记或执行状态；选中后在右栏原地展开，标题栏提供返回工作台、最大化与收起。审阅只阅读工具确认的文件变更；工作区只读本地 Git 的 HEAD 与当前文件差异，标注「不代表任务记录」，不提供暂存或提交；工作台不提供页签添加、页签关闭或未接入能力的占位入口。

运行事件按“任务 → 明确身份的推理或能力调用 → 原始事件”组织。交互摘要取实际声明的动作与目标，未加载声明时明确说明。没有操作关联的记录保留在原位置，不按相近时间或相似工具名推断阶段。筛选包括工具与能力、具体来源、模型推理、失败、需关注和人工介入；任务终态始终取终态事实，不因局部失败而改变。

主对话不提供计划浮层，也不把计划放进执行摘要。创建与结构修订在历史位置只占一行计划事件（标题、步骤数、模型声明），点击查看版本与步骤变化；当前计划另在输入区上方显示一行标题与步骤进度，点击展开全部步骤；完整修订在活动中阅读。执行摘要只汇总已加载调用数、工具确认的文件变更构成、当前片段状态与已知耗时，并提供「查看全部活动」进入完整活动。状态通过图标表达，辅助技术能读出完整状态；计划来源标注「模型声明」并使用辅助字号，不与执行结果混同。

设置采用 [主窗口内的设置工作区](../decisions/settings-workspace.md)，普通控件列为 196px，组间距 16px；策略和模型服务进入二级详情，小弹窗仅承担局部确认。主对话阅读宽度、全局字体、圆角和配色不因这些局部调整改变。

## 设置能力来源的发现入口

遵循 [只读来源浏览](../decisions/provider-browsing.md)：两列 88px 横向小卡片，仅用于 Provider 发现；后续层级为紧凑能力列表与独立契约详情，不递归使用卡片，也不做左右管理面板。搜索可直接定位内部能力，Schema 默认字段概览并支持原始对象阅读。所有数量、说明、来源与执行声明均来自实际注册信息。

## 连续执行与计划投影

主对话的具体行为遵循 [计划声明与连续执行流](../decisions/task-plan-declarations.md) 和 [主对话组件映射](desktop-conversation-ui.md)。计划创建与结构调整使用低存在感的一行计划事件，主对话与完整活动共用同一形态，纯进度更新不新增节点；当前计划由输入区一行入口展示。公开反馈文本开始一个自然段落，后续连续调用作为缩进工具组附在其后；没有公开反馈时只显示中性工具组，不编造阶段名称。累计摘要每 Turn 一行，展开为调用列表，调用明细默认收起。人工询问和授权保留独立语义，待处理时使用明确交互边界，完成后原位收成一行。主执行流共享对话滚动，只有历史弹窗及长输出保留局部滚动。


### 能力来源的资源浏览例外

一级来源与二级能力均为双列小卡片，窄内容区域收为单列；详情保持单一阅读区。资源图标使用随应用打包的原始彩色图集，功能图标使用 Phosphor regular；主题不修改图集内容。卡片描述限制两行，完整声明在详情阅读，来源标签不得因描述截断消失。实现边界见 docs/decisions/provider-browsing.md。


### 技能新增入口

能力来源首页和 skills 二级页在宿主支持时提供“创建技能”“导入 SKILL.md”。操作在当前内容区进入编辑页，不新增窗口；导入仅支持单个文件，附属资源限制明确提示。成功显示实际路径与“待重启加载”，不将磁盘新增伪装成 Camp 已注册能力，不自动重启或中断任务。创建与导入的边界见 docs/decisions/local-skills.md。


### 技能编辑页的排版

创建与导入技能使用最大 640px 的单列编辑区，宽度随窗口收缩。顶部为轻量返回导航、技能图标、18px 标题和次级说明；共享 FormField 在此页清除上下外边距，仅由 16px 表单间距控制节奏。正文编辑区初始约 200px，可纵向调整，不自动铺满视口。

底部轻分割线组织加载说明、取消和保存按钮；窄窗口自然换行。格式与容量说明贴近字段，不在页首堆叠。保存期间输入与退出操作禁用；本页返回和取消在未保存时使用共享确认框。编辑、保存和待重启加载的宿主语义保持不变。

执行流中同一自然段落内正文与工具组间距为 8px，自然段落之间为 24px；连续纯活动片段间距收紧到 12px，用户输入、答复与人工交互边界额外保留 16px 停顿。公开反馈作为段落起点，后续连续工具缩进分组。原始推理不进入主对话，只在完整活动中按 INFER 记录阅读。工具沿真实顺序显示动作和目标，折叠行按已提交调用显示读取 / 修改 / 执行分类计数；长命令限单行省略，调用完成不推断任务阶段完成。


### 紧凑活动流与历史收敛

对话简版由公开反馈文本切分自然段落：正文保持常规阅读层级，段落内连续工具使用 32px 缩进短行，已结束调用折叠为一行“工具活动 · N 次调用”，短行显示已提交的 `durationMs` 耗时；运行中、失败与未知调用保持可见。每 Turn 只有一个单行累计摘要，不替代这些段落。工具参数、输出与已提交授权记录通过单次操作的详情阅读；已授权只显示小型辅助标记，不能表示执行成功。

每个自然段落只折叠连续完成的成功调用，折叠块保留在原事件位置；失败、未知与运行中调用不被折叠。用户展开的折叠块与累计摘要不被状态刷新或流式文本自动关闭。只有明确的 Turn 结束事实才改变累计摘要状态；断连、暂停、取消请求或 active=false 不推断任务结束。公开进度和原始推理在完整活动中分开展示；临时流明确标记未提交。

用户补充输入、待授权/待回答、失败、非零命令退出码、未知、取消与最终答复保留独立位置。计划创建/结构修订在简版中只保留一行计划事件，纯进度更新不新增节点；当前计划另由输入区入口展示，完整历史仍在活动中可查。历史窗口不跨这些边界，也不把模型推理次数或计划步骤当作业务阶段。当前人工表单按 turnId/effectId 强制留在主流，即使恢复标记已到达也不遮蔽。最终回复只显示一次；原始数据和日志不改写。部分历史的调用数标为“仅已加载记录”，不声称完整数量。

键盘使用原生按钮与 details/summary；展开详情与打开检查器分别表达相应语义。长路径单行省略但可在详情完整阅读，状态与计数不被挤出阅读区。所有尺寸与颜色沿用集中 Token，普通行无新卡片或阴影。


### 活动、计划与命令授权的局部层级

普通工具行不使用逐行分割线或成功勾选。目录、搜索、文件和编辑使用对应语义图标；文件类操作优先展示文件名，父目录在同一行降为次级并省略显示，原始完整路径仍在按钮可访问名称、提示和详情中。失败、未知、等待及重试事实不改写；单次耗时只取已提交的 `durationMs`，尝试次数与完整参数输出仍在详情中。当前运行状态只显示“正在分析…”等短文案，不显示阶段毫秒计时。

输入区计划入口默认只占一行，展开后显示声明步骤，当前阶段使用浅强调表面；不生成阶段副标题、不改变模型状态或完成数量。调用明细由对话内独立的原生 details 控制，与计划入口互不影响；后续声明更新不自动展开或关闭计划入口，也不覆盖用户已做的展开或收起选择。

命令授权保留在主对话的当前操作位置，标题为“等待命令授权”，命令使用低反差代码表面。参数明确声明 cwd 时标注“命令目录（参数）”；否则显示当前工作区参考或未加载提示，并在详情明确由宿主解析实际目录，不能从 Shell 字符串或当前工作区推断执行事实。命令文本不改写。操作详情和标准按钮共用紧凑底栏，按钮为“拒绝并结束任务”“允许本次执行”，不增加额外授权范围或自动审批。新人工交互聚焦自身且不强制滚动。


### 严格单行活动摘要

公开进度与工具按效果原序穿插；只有公开文本生成主对话段落，原始推理不进入简版。工具短行固定 32px、不换行；文件名、目录和命令预览在可用空间内省略，完整目标仍在可访问名称、提示和详情中。窄窗口不得把目录移到第二行，也不把推理记录集中放到段落末尾。

活动页中的推理记录使用记录行打开同页的单条事实详情，临时和中断内容明确标注，最终答复不重复进入摘要。授权、人工回答、计划内容和最终回复不受单行摘要约束。历史收敛和异常边界保持不变；这里只改变显示，不修改事实时间或执行策略。


## 命令授权与完全访问确认

等待命令授权使用警告色标题与轻边界，内容区保持中性，主操作保持品牌色。警告表示需要明确决定，不表示命令已经失败。

从其他模式选择完全访问时，先显示范围确认，默认聚焦取消。当前任务存在时，确认仅改变当前任务；若正等待命令授权，明确提示同时批准该命令。没有当前任务时，确认改变后续发送任务的默认模式，直到用户主动切换。命令使用宿主权限，可能访问工作区外文件和网络；文件工具访问范围不随此选择改变。

弹窗固定任务、配置 revision 和等待项。取消不提交；确认时状态发生变化则报冲突，需重新确认。模式切换与当前命令批准由 Runtime 一次提交，界面不通过先切换再回复来拼接操作。授权成功不等于命令执行成功。


## 轮次内计划与阻塞优先级

计划不占据对话阅读面：创建与结构修订只在历史位置保留一行计划事件，当前计划另在输入区上方以一行入口展示，点击展开声明步骤；对话中的累计摘要只汇总调用、文件修改与片段状态。授权、询问与未知结果对账仍在发生位置展示，不需要为计划让出位置。没有声明时不显示计划入口或事件行，也不补造步骤或完成比例。两种情况都不增加浮层或覆盖层。

计划入口在 Turn 运行中显示，不推断跨 Turn 继承；调用明细默认收起，用户手动切换后，后续状态更新不重新覆盖该选择。收起使用原生 details 隐藏内容，不保留定位残留，也不需要 Esc 或外部点击规则。长文本不得撑出横向滚动条；窄窗口下步骤自然换行，不改变阅读顺序。

### 输入区图片附件

新对话和会话输入区共用官方 Prompt Input（Input Group + 附件上下文），通过粘贴、拖拽输入区或工具条附件菜单选择图片；会话输入框保留“继续这段对话…”提示，新对话输入框不显示占位文案。
无附件时不渲染附件行；添加后在文字上方显示官方附件条目（缩略图、文件名与移除图标）。
每条消息最多四张图片，单张最大 5 MiB；超出类型、数量或容量时不加入并给出可读提示。
读取过程中禁止提交；成功发送后清空，提交结果未确认时保留原快照。
历史消息在用户气泡中显示图片，尺寸受阅读区约束。
文本粘贴使用原生选择区替换与撤销行为，长文本保留完整内容，不因换行自动提交。


### 对话工作区的阅读层级

浅色外观使用冷灰导航、白色阅读面与石墨正文；深色外观使用分层石墨表面。强调色只影响当前项目的文件夹图标、主按钮、焦点与少量活动标识；会话选中使用中性浅表面，避免父子两行同时出现强调条。Slate Teal 与 Carbon Amber 等强调色可与四套界面主题自由组合，保持同一结构与语义。输入区使用由辅助表面与面板混合的 `--surface-composer`，文本框透明，维持单一边界，聚焦时强调边界。布局、字号和授权入口不随主题变化。

执行行以动作、文件名、目录形成三级层次：动作使用辅助字号，文件名使用 medium 正文色，目录使用辅助字号与弱文字色。目录存在时文件名最多占目标区域的 60%，长目录先省略，完整路径仍在提示与详情中可读；命令与无目录目标仍允许收缩。思考预览使用辅助字号与弱文字色，不与正式答复争夺层级。不添加示例结果或推断成功状态。

验证运行桌面构建、类型检查、Lint 及主题、阅读布局、执行记录与过程呈现测试；这些检查不替代 Electron 实机视觉验收。


### 会话正文与续聊输入

续聊输入使用白色面板、单一细边界与 12px 内边距，正文至少 32px 高，底部工具栏与正文间隔 12px。空输入明确显示“继续这段对话…”，不依赖仅有的模型控件提示输入用途；首页仍保留辅助表面。窄窗口继续沿用控件换行和发送按钮固定可见规则。

任务结束后的失败或取消说明使用正文层级，带语义图标但不使用输入框式警告面板；完整原因、任务结果与需关注入口仍保留，运行详情默认折叠。结果摘要仅保留顶部分隔，不重复上下封框。此调整不改变失败事实、授权、重试或恢复行为。验证采用桌面构建、Lint、阅读布局和执行记录测试，窗口视觉仍需 Electron 验收。


### 运行中输入与授权确认

命令摘要使用 regular 等宽辅助字号，不将整条命令加重；原文、路径、参数与详情保持完整。发送方式位于输入区底部控件层，正文先呈现输入提示。停止任务独立位于输入框上方右侧，操作当前任务；发送按钮只负责当前输入。停止的可用性仍由真实任务及取消状态决定，不依赖输入框展开。

完全访问确认沿用共享 small 弹窗与标准标题，范围说明使用操作字号，权限边界使用辅助字号。底部不重复分隔，取消使用中性表面，确认独占强调色；默认聚焦取消、Esc 关闭、当前任务和后续任务的授权范围均不变。验证覆盖授权、消息提交、执行记录与阅读结构测试及桌面构建和 Lint。


彩色资源图集必须作为源码资源保存在 `apps/desktop/renderer/src/assets/capability-icons.png`，由样式静态引用并随构建打包；不得因主题调整删除或替换图集。验证检查资源存在、桌面构建无图集解析警告及能力来源测试。


连续执行节点使用 4px 间距；用户消息、任务边界与答复继续保留独立停顿，避免折叠记录与单条调用间重复留白。验证可使用 `pnpm dev:desktop` 的 Electron 窗口观察已有会话，修改样式后通过热更新确认；不需要发送消息或触发模型调用。

### 活动调用检查

活动默认按已提交 INFER / CALL 的稳定 Turn 与 Effect 身份聚合为一行，不按开始、结果事件重复计数，不改变日志与执行机制。表格保持事实顺序，展示时间、类型、名称与参数摘要、真实状态、已提交耗时和模型输入 / 输出 Token；缺失指标显示 `—`，不估算。搜索覆盖请求参数，可按全部、模型、工具与失败筛选。上下方向键移动选择，后台追加不抢占选择。

详情提供输入、输出、指标与事实三个页签。模型输入展示实际提交请求快照，包含整理请求的 purpose；工具输入展示固定能力引用与参数。输出保留已提交结果或错误；未记录内容明确说明，不由临时流补造。指标与事实保留关联原始记录，来源、用量及恢复状态可追溯。取消请求不转换为已取消，结果未知不转换为失败。

宽容器并列展示列表和详情；窄容器选择后仅阅读详情，关闭返回原列表。切换调用与全部事件保留各自组件状态。已加载调用数只描述当前历史窗口。全部事件仍支持授权、配置、输入、计划及恢复事实查阅。验证运行桌面类型检查与 event-panel、event-navigation、conversation 行为测试；界面验收覆盖窄容器、长参数、结果未知和后台追加。

调用表行高固定为 32px，名称与参数摘要同行，所有单元格禁止折行，超长内容省略后在详情查看。筛选位于工具栏左侧，搜索位于右侧；窄容器允许横向滚动，不将控件堆叠或将记录撑成多行。

调用类型筛选使用 `@archer/ui` SegmentedControl 横向直接展示“全部 / 模型 / 工具 / 失败”，选中项使用轻量圆角底色，其余项使用辅助文字，不使用下拉菜单。搜索保持在右侧；任务身份在列表摘要与详情中查看。

“调用 / 全部事件”视图入口及全部事件中的类别筛选同样采用轻量横向分段选择，避免同一活动页混用不同的主筛选交互；具体工具的长候选列表仍按需提供下拉选择。

活动工具区统一为两行：首行左侧按内容宽度排列“调用 / 全部事件”，右侧共用搜索；次行左侧类别筛选，右侧淡化数量统计。分段按钮不等分可用宽度，使用紧凑文字和轻量选中底色。全部事件搜索匹配已提交事件原文，不补造关联事实；清空搜索可恢复完整已加载事件。

活动详情标题使用全局导航字体（默认 13px）和 medium 字重，状态、编号、说明及详情页签使用辅助字体（默认 12px）。原始 JSON 使用全局代码字体（默认 12px / 18px），保留缩进、不强制折行，并在内容区横向滚动，避免拆断标识符或撑宽面板。字号仍跟随全局文字大小偏好，不修改应用正文或全局 Token。

设置侧栏搜索使用 `@archer/ui` 的 InputGroup、InputGroupAddon 与 InputGroupInput，统一绘制边框与焦点态。顶部“返回应用”使用 ghost Button 与辅助字号，按内容宽度排列，不绘制常驻按钮边框。返回与搜索行为保持不变；验证检查桌面类型检查，以及搜索聚焦时只有一层边界、返回操作可键盘访问。

## 会话导航的选择与执行状态

选中对话时仅对话行显示选中背景，所属目录通过展开箭头表达层级，不同时高亮；仅直接选择项目且尚未进入对话时目录可显示选中背景。会话左侧直接展示标题，不渲染前置图标或保留图标占位，右侧复用 shadcn `SidebarMenuBadge` 作为状态与排队数量的共同容器，与「…」菜单分列。状态圆点是宿主提供的展示内容，不是官方独立 StatusDot 组件：进行中使用复用 Spinner 的灰色旋转圆环，失败使用 Danger Token 红点，等待确认与正在停止使用 Warning Token 圆点；完成与已停止不显示圆点。提醒圆点无动画，运行圆环遵循减少动态效果偏好，悬停说明与无障碍名称提供中文含义，不仅依赖颜色；圆点不表示消息未读。

无任务事实或读取失败不推断已完成；空闲会话通过最近一条 Turn 查询获得终态，活跃任务优先使用当前快照。完成仅表示最近一次执行结束，不代表整个对话关闭或语义验收通过。仅改变展示，不修改 Runtime 或持久化协议。验证覆盖新任务不被旧终态覆盖、六种任务状态的提醒规则、无任务边界；桌面验收检查长标题、排队数、圆点与菜单不重叠以及悬停说明。

会话标题末端使用透明遮罩渐隐，超出宽度直接隐藏，不显示省略号，不覆盖选中背景。状态槽固定在行尾最右侧，菜单在其左侧悬停或键盘聚焦时显示，排队数位于菜单左侧，预留空间防止标题位移。完成与已停止不显示提醒；不以完成事实推断未读，不展示缺少查看记录支撑的完成蓝点。验证包含长短标题、窄侧栏、深浅主题、菜单聚焦、状态和排队数同时出现。

会话按钮铺满所在行宽，背景包含右侧状态与菜单区域，不以标题内容决定按钮宽度。标题仅在末端 8px 内渐隐；选中背景使用 `--accent-subtle`，悬停使用 `--accent-subtle-hover`，跟随预设或自定义强调色；正文保持正常颜色，不增加彩色描边。鼠标点击不显示外侧强调色焦点环，键盘导航保留中性行内细描边。验收检查短标题背景同宽、状态点位于背景内、长标题末端渐隐以及鼠标与键盘焦点区别。

审阅文件树与正文使用 `@archer/ui` ResizablePanelGroup / ResizablePanel / ResizableHandle，分隔线支持拖动及键盘调整；树列至少 140px、最多占当前审阅区 50%，正文至少 180px。审阅区宽度小于 600px 时默认收起文件树，可通过工具栏显式展开，用户选择优先于默认响应式布局。阅读区源码不受会话工具输出的 360px 限高约束：代码块按内容自然撑开并由阅读区整页滚动，不产生嵌套滚动框。工作台保存本机像素宽度偏好，恢复后仍由当前容器约束实际宽度，不改变任务事实、文件内容或恢复语义。验证包括宽度偏好保存与恢复测试、桌面构建；实机验收拖动外侧及树列分隔线、缩窄窗口、展开收起树、最大化与键盘调整。



导航与工作台统一使用 `@archer/ui` 的 ResizablePanelGroup、ResizablePanel 和 ResizableHandle，底层由 react-resizable-panels 管理指针、键盘、尺寸约束和实时跟随。左侧不保留自定义 pointermove、动画帧、尺寸预览或临时样式方案。导航展开范围为 260–420px，折叠固定为 56px 图标轨，移动端导航面板为零宽并继续使用 Sidebar 抽屉；展开恢复已保存宽度，不重建会话。Sidebar 在桌面面板中使用普通定位，取消原 fixed 容器与占位的重复宽度控制。

导航与右工作台只在公共组件报告用户调整结束时保存本机宽度，拖动过程不写全局状态；审阅与上下文分栏保持局部布局。导航分栏包装仅负责选择宽度偏好及折叠映射，不实现第二套拖拽。验证运行 UI 和桌面构建、宽度偏好测试；实机需验收左右拖动、键盘调整、折叠后恢复宽度、移动端抽屉与长会话流畅度。

## 首页与项目命令偏好

首页欢迎标题与副标题分行，项目入口位于输入框上方，通过下拉菜单切换已有项目或打开文件夹，完整绝对目录通过提示呈现。输入框使用语义表面色的轻量混合，聚焦沿用统一边界；移除重复授权提示，推理等级保留中文值与无障碍说明。

命令模式默认偏好按服务身份与项目绝对工作目录持久化。同一项目的不同对话共享后续发送任务的默认模式，不同项目和不同服务互不继承，未设置时为每次询问。完全访问必须通过确认弹窗，弹窗说明项目范围；已有会话级偏好不迁移为项目授权。每个已接受任务仍固定自己的授权快照，项目偏好修改不改变执行中、排队中或提交结果未知的请求。运行中的授权入口在服务端提交成功后，同时保存该项目的默认模式；完全访问确认明确说明当前任务与项目范围，不改变其他已接受任务。当前命令批准成功后立即撤下对应等待卡片，无需等待状态查询刷新；请求失败时保留卡片。后端 turnId、revision 和重新准入规则保持原样。

验证包含项目偏好刷新恢复、项目与服务隔离、非法值过滤、任务提交重试及授权确认测试。运行 `pnpm exec vitest run tests/desktop/renderer/project-preferences.test.ts tests/desktop/renderer/authorization.test.ts tests/desktop/renderer/submissions.test.ts --maxWorkers=2` 和 Desktop typecheck；实机检查首页菜单、完整路径提示、完全访问范围与明暗主题。


停止反馈在任务结束处统一显示「执行已停止」，默认不重复说明「任务已停止」。终态替代对话中的停止请求提示；队列暂停与恢复由输入区呈现，不在正文重复插入通知，原始过程事实保留在活动页。重启恢复由 Runtime 折叠日志后提交恢复事实；已开始的 CALL 结果无法确认时进入结果未知，不能仅因重启标记成功或已停止。验证运行 execution-timeline 测试及桌面构建。

纯停止回执分组不展示 Archer 署名与品牌图标；同组存在实际助手正文或工具活动时保留署名，避免把系统停止状态表现为新的助手答复。

已隐藏的状态通知在建立阅读分组前过滤，不产生空轮次或间距；纯停止回执不叠加轮次停顿与最终答复上边距，紧接前面的执行内容。

完成、失败、停止共用执行回执：正文和文件变更在线上方，细分割线下统一显示状态、调用次数、耗时与可展开的执行详情。停止不再单独显示警示块或查看活动链接；失败原因在回执下呈现。边界复用语义颜色和间距 Token，不改变事实与任务状态。

执行回执的状态、调用次数与耗时靠左，执行详情入口靠右并保持同一行；展开内容独占下方整行。文件变更与回执分割线间保留 space-5，线下使用 space-3，分割线使用 border 语义色保证可辨识。

执行回执状态使用图标与中文文字共同表达：完成为勾选、失败和受阻为警示、停止为停止图标；执行中与正在停止保留 Spinner。状态采用正文刻度和 medium 字重，统计保持辅助字体；完成使用 success、失败使用 danger，停止使用中性主文字，不以颜色作为唯一辨识方式。

公共状态组件修改后的验证需先构建 @archer/ui，再构建 @archer/desktop；桌面通过包导出引用 ui/dist，单独构建桌面不会更新公共组件产物。可执行 `pnpm --filter @archer/ui build && pnpm --filter @archer/desktop build`，再重新打开窗口检查状态图标。

对话通知的可见性在阅读分组前统一确定，渲染阶段不重复过滤相同状态；结果区只由执行回执维护分割线，文件变更不再依赖旧的摘要内部嵌套结构。验证覆盖 execution-timeline 行为测试和桌面构建。
