# 桌面组件与视觉约束

字体、字号、字重、行高、图标尺寸和间距集中维护在 apps/desktop/renderer/src/ui/theme/design-tokens.css。功能图标用 Phosphor regular，经 Icon 的语义名和 xs/sm/md/lg 尺寸使用，不混用图标体系。全界面以 Codex 的比例、密度与克制层级为参考，明暗模式、界面主题与强调色三个维度自由组合：界面主题有 Graphite、Midnight、Slate、Warm，强调色有 Graphite Iris、Slate Teal、Carbon Amber、Dusty Rose 与自定义 HEX，默认深色、Graphite、Graphite Iris；界面主题只覆盖中性层，强调色只覆盖 Accent Token。所有颜色从语义 Token 读取，新增主题不得修改业务布局或结构刻度。页面与组件按桌面应用设计，不采用管理后台式卡片堆叠；设置中的文字大小等简单互斥偏好使用行内分段选择，外观设置使用界面主题缩略卡、强调色单选行与可折叠实时预览，不使用大选项卡。右栏是工作台：首页列出审阅、工作区、活动与会话概览四项，选中后在同一右栏阅读，审阅使用任务回执展示修改前后内容，无需 Git；工作区独立读取本地 Git 未提交改动；中间固定标签只承载会话、活动与上下文，活动页默认以紧凑调用表定位 INFER / CALL，同页查看输入、输出与指标事实，并保留全部已提交事件入口；不提供会话概览或能力来源二级视图；上下文页按已提交 INFER 请求快照扫描字符组成与条目：顶部请求指标，左栏用可折叠字符条带表达正文字符占比、以真实输入 Token 画近期趋势并配默认收起的可折叠条目分组，右栏阅读请求概览、已选上下文与整理事实，「结构 / 原始内容」子视图复用 Resizable、ScrollArea、Tabs、Collapsible 与 Tooltip，统一使用 `@archer/ui` 的条目、输入、选择与按钮组件，遵循 docs/design/desktop-baseline.html 的四态结构与 docs/decisions/desktop-visual-baseline.md 的比例，不在对话内堆叠 Diff；工具栏的图标尺寸只约束直属按钮，不得用后代选择器影响嵌套菜单。答复底部的模型与累计用量默认折叠，不占据阅读主层级。上下文整理只使用一处轻量阶段提示，历史按整轮折叠，不使用醒目状态卡片或在每次推理间重复插入记录。按钮、输入、多行输入、弹窗、菜单、浮层、页签、提示与 Sidebar / Resizable 统一从 `@archer/ui` 导入，不在业务组件定义第二套控件或浮层视觉。对话区使用 AgentTurn、TurnSummary、ActivityGroup、Plan、InteractionRecord 与 AssistantAnswer；运行中计划默认展开、已完成计划默认收起，进度只表示声明值；正文 Mermaid 跟随界面明暗。未来 Web 不复用桌面界面源码。品牌独立；目录 medium、正文 regular，详情见 docs/guides/desktop-visual-system.md。

新增或调整界面前，先检查 `@archer/ui`、组件目录与项目已有组合，优先复用现成组件；没有专用组件时优先组合现有原语，不在业务层重造控件、滚动容器或浮层。会话定位条使用 Button、Tooltip、ScrollArea 组合，位于会话阅读区右侧垂直中间，长列表有界滚动。

答复底部的文件变更使用 Item 系列组合成轻边框预览，标题旁集中展示文件数与分类，默认展示前三个文件，超过三项时通过 CollapsibleTrigger 展开其余列表，复用 ScrollArea 有界滚动。每个文件只出现一次，点击仍进入右栏审阅，无跳转目标时保持只读。标题与文件名使用 text-primary 主文字色，路径、统计和展开提示使用 text-muted；汇总中的新增数量与文件新增状态同时使用 success 文字色，修改与未知保持中性色及文字说明，不使用彩色标签底色。摘要没有可信行数统计，不补造增删行数。长路径可收缩并由 Tooltip 提供完整路径。标题采用全局操作字号，文件名采用导航字号与 medium 字重，路径和统计采用辅助字号；文件说明清除正文段落外边距，两行紧凑排列，行内垂直间距为 space-1，图标与名称顶部对齐、状态居中；路径显式覆盖正文段落的 margin、padding 和字体，标题与展开入口的内部分隔保持直线、不继承 Item 圆角；间距与列表高度复用全局 Token，不增加局部视觉刻度。只读行不显示跳转箭头或交互悬停。标题行在具有审阅目标时提供公共 ghost Button「查看差异」，直接进入既有右栏审阅，不另建 Diff 界面。展开入口左对齐，箭头表达展开状态。执行详情以顶部细分隔延续结果区，统计紧邻行尾箭头，保持次要层级。此布局只展示已提交的历史事实，不改变执行与恢复机制。验证使用 Desktop typecheck、task-insights 与 changes-panel 测试；实际窗口检查预览、展开收起、长路径、窄栏及明暗主题。

Git 比较范围、按文件读取和共用差异组件见 [工作区差异与历史审阅](../decisions/workspace-git-diff.md)。

审阅与工作区的源码、差异及工具修改详情统一使用 CodeBlock 外壳，保留路径、复制、代码字体和边界；差异模式只在两侧均有内容时提供紧凑的统一 / 并排切换。切换行为由 diff-layout 测试验证。

代码展示优先复制 shadcn/ui 官方 Code Block（Base UI），通过其组合 API 接入；CodeSnippet 仅负责文件内容与官方高亮 hook 的组合，不自定义外壳。

审阅与 Git 阅读统一保留代码视图，不设置差异 / 源码 / 预览切换。文件树样式独立于代码块，目录的箭头、图标和名称不得换成三行，层级缩进和选中态保持不变。

文件阅读区同一路径只显示最新已记录片段，不堆叠早先代码块；旧侧未知与已知差异均使用 Pierre 的同一代码渲染体系，不切回另一套源码视觉。

公共交互组件的原语职责、受控状态与关闭边界见 [公共交互原语](../decisions/ui-interaction-primitives.md)。

Git 差异使用传统 + / − 行标记和增删背景，Git 工作区默认比较 HEAD 与工作区，不能把全部仓库改动宣称为任务独占修改。

write 与 edit 的任务回执用于无 Git 项目的审阅，已知两侧显示 + / −；未知旧侧不推断为空，不用 Git 当前内容补造历史。

活动页、时间线和历史记录的展开统一使用公共 Collapsible；折叠保留已加载事实，不以隐藏代替删除。
工作台、上下文图表及原始事件阅读入口复用公共 Button，Item 的 render 按官方组合使用原生按钮。

当前推理的等待提示置于所属工作轮内，紧跟署名与已有正文；空活动投影不撑开间距。
没有流式内容时显示「等待模型响应…」，收到思考分块才显示「正在思考…」，统一使用公共 Spinner。
流式正文出现后由原位预览承担反馈，不叠加普通等待行；停止、暂停、中断和未知结果仍保留明确提示。
此布局不改变推理、提交与恢复。验证运行 execution-timeline、context-status 与 reading-layout 测试及桌面类型检查。

紧凑对话中，Archer 署名、时间与本轮累计活动摘要共用顶部行；摘要仍复用 TurnSummary，
统计保持辅助文字，需关注状态保留强调色，活动入口靠右。窄窗口统计自然换到第二行，不隐藏指标。
公开正文、具体调用和人工交互仍按事实顺序位于顶部行下方，不因合并摘要而重排。
验证由 execution-timeline 的顶部行结构、摘要唯一性与正文分离测试覆盖。
